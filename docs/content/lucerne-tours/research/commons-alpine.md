# Wikimedia Commons photos for alpine gaps

Base dir: `/home/ross-geller/Projects/minastik/swiss-keepsakes/docs/content/lucerne-tours/images-commons/`
Licences and authors were read from the Commons API (extmetadata) and each file was opened and checked visually. File page URL pattern: `https://commons.wikimedia.org/wiki/File:<Name>`.

Summary: genuine photos for all 7 slugs. No full GAPs. Partial caveats: finsterwald-honey landscape shows Entlebuch meadows and forest but no visible moor; the beehouse is in Obwalden, not Entlebuch itself; gotthard Tremola only has a modest 2004 photo (Unsplash stays the better default).

- Chosen: `grimsel/Grimsel_Hospiz_Hotel.jpg` (1920x1417, ~737 KB)
- Page: https://commons.wikimedia.org/wiki/File:Grimsel_Hospiz_Hotel.JPG
- Title: Grimsel Hospiz Hotel. Author: Paebi. Licence: CC BY-SA 4.0 (2014-08-28).
- Shows: stepped-gable stone facade of Hotel Grimsel Hospiz with red shutters and the "HOTEL GRIMSEL HOSPIZ" lettering, mountains behind. Daylight, no people. It is a building portrait, with no reservoir.

It is a tight crop of the dam, so it reads as engineering and not as a landscape.
