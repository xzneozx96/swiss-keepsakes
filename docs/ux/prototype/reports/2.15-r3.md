## What the first run found, and what was done

1. **Clipped German tour names on C14 (real bug).** In past bookings, long German names were cut mid-word ("Altstadtspazie Luzern", "Über den Vierwaldstätte"). The name column beside the price is narrower than a German compound, and `line-clamp` hides the overflow. Fix: `break-words hyphens-auto` on the name (with `lang`), on both the tour row and the identical gift row in `transaction-list.tsx`. Names now break with a hyphen ("Altstadtspa-ziergang…"). The longest ones still end in an ellipsis after two lines, exactly as gift rows do.
2. **C09 "Whole route now offered" (test timing).** The button is enabled once the camera finishes flying to the stop. That took longer than the fixed 600ms wait while four servers ran. The test now waits up to 5s.
3. **C16 policy text (stale test, flagged by worker G).** Round 3 moved the policy snapshot onto C16's Policy tab, so the test now reads it there.
4. **`useDemo must be used inside DemoProvider` in a re-run (dev server, not the app).** After hot reloads triggered by edits during the session, a long-running Vite server served two copies of the demo-state module (`?t=` URLs). Restarting the servers fixed it, and the owner's 5173 preview was restarted for the same reason. The production build is unaffected.
