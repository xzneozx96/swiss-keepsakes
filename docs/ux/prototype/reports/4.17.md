# N16 and N17 notification demos

15 October 2026. Step 4.17 is built and awaiting the owner's batch review.

The two emails appear in the existing simulated mailbox (the Mail panel in the prototype bar, **Staff** tab).

## Review the changes

As the guest, send a trip-advice request on `#/plan` (C21) and a private-tour request on `#/tours/private-tour` (C22), then open the Mail panel (envelope in the prototype bar) and its **Staff** tab.

- **N16 New advice request** is sent when C21 sends.
  - **To:** the recipient address set in M19 (`requests@swisskeepsakes.example` in the seed).
  - **Language:** always the shop's default, English (D10).
  - **Subject:** "New advice request from {email}".
  - **Body:** the time, "Guest email", "Guest language", then every question **as the guest saw it** with its answer ("Wie viele Erwachsene reisen mit? — 1" for a German guest). A closing line says skipped questions are left out and asks the shop to reply by email.
  - **Button:** "Open the request" opens the request in M19.
- **N17 New private-tour request** is sent when C22 sends, as two emails.
  - **Recipients:** one to **Chị Ngọc (Owner)** in English and one to **Lukas (Store Manager)** in German, each in their interface language.
  - **Body:** a greeting by name, the time, "Group: 6 people", "Preferred dates: 24.10.2026 – 25.10.2026" (one date for a single day), "Interests: …" (left out when empty), the guest's email and language. It ends with "Reply by email … then mark the request as answered."
  - **Button:** "Open private tour requests" opens M20.
- **The links work from any role.** The button closes the panel and opens the request. If the presenter is still the guest, it switches to the recipient first: the Owner for N16, the Owner or the Manager for N17. Otherwise the shell would show a merchant page under a Guest bar.
- **The guest gets no email (A2).** The Guest tab count does not change after either request.
- **A recipient change in M19** applies to the next N16.

## Decisions to confirm

- **N17 staff languages are a prototype assumption.** The spec says internal mail uses each recipient's interface language, but the demo data stores no staff language. N17 assumes the Owner works in English and the Manager in German (`requestStaff` in `features/requests/lib/request-mail.ts`), so both languages show. The older staff mails (N03, N21, N11, N22, N23) still go out as one "Shop staff" email in the current UI language. Align them later or tell me to change N17 to match them.
- **N16's question wording is not translated.** It is copied as the guest saw it, so a German guest's questions appear in German inside the English email. This is the same snapshot as the M19 detail (AC18). The mail keeps its own copy, so later edits to the question set don't change it.
- **N17 also states the guest's language.** The spec lists group, dates, interests and email. I added the language because it tells the shop which language to reply in.
- **N17 links to the M20 tab, not to the single request.** M20 has no detail route (outline §3), and the request is the newest one at the top of the tab. N16 opens its own request in M19.
- **N16 counts as a Staff mail.** It goes to the shop's request address rather than to a person, so the To line shows that address.
