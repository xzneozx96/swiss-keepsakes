- **Empty states.** "No comments yet. They appear here as soon as guests post them." With a filter: "Every comment has a reply." or "No hidden comments."

## Decisions to confirm

- **Filters.** The filters are All, Not replied and Hidden. Not replied is the shop's to-do list. The spec names only hide, delete and reply.
- **One flat list.** Replies are their own cards, so each one can be hidden or deleted on its own. Only top-level comments take a reply.
- **Hide hides the thread.** Hiding a comment hides its replies on C20, since they would make no sense alone. Showing it again brings them back.
- **No confirmation for Hide.** It is reversible. Delete always asks, with the shared dialog.
- **Shop replies can be hidden or deleted** like guest comments.
- **Time.** The time shows in Zurich time, with the hour, so the shop can tell same-day comments apart.

## Note open items

- **Time zones.** C20's dates use the app's shared `formatDate` in the browser's time zone (since 4.4). M18 shows Zurich time. On a computer outside Switzerland, a comment posted late in the evening can show the next day's date on C20. The test machine runs at +07:00, which showed this.
