# Step 1.16: C18 Write a review

## 1. What I built

**C18 Write a review** is a bottom sheet that opens from the review slot on C15. It is not a new route.

- **The slot.** On a completed order, C15 shows **Write a review** in the action block. It replaces the disabled "Coming in a later step" placeholder that 1.13 left. Orders in any other state show no review button. The gate is still 1.13's `status === "completed"`.
- **The sheet.** It shows:
  - the product reviewed: photo, name and the variant as ordered (AC15 snapshot)
  - **Your rating**: five stars, built as a HeroUI `RadioGroup`, so it has arrow-key and focus behaviour; each star is labelled "n out of 5 stars"
  - **Your review**: a text field of up to 1000 characters
  - **Post review**
  - a note: "Your review appears on the gift page with your purchase date."

  Validation runs on submit. "Choose 1 to 5 stars." and "Write a few words about the gift." appear inline and clear once the field is filled. The sheet has one overall rating only, as decisions.tsv requires.
- **Submit.** Submitting stores a `Review` in `data.reviews` through `useDemo().update` and shows the toast "Review posted. Thank you.".
  - `id` is `rv-<orderId>-<productId>`, so each product in an order gets one review (spec §4.11).
  - `guestName` is "Anna K.", in the same style as the seeded reviewers.
  - `purchasedAt` is `order.completedAt`.
  - `text` is stored only in the language it was written in. The other language shows the existing "Text auf Englisch" note.
  - The hook re-checks before it writes: the order is completed, it belongs to the signed-in guest, and the product has no review yet. The update recipe checks again, so a double tap cannot add a second review.
- **Already reviewed.** The button is replaced by "Your review of {product}". The card shows the review exactly as C03 renders it (`ReviewItem`, "Purchased on Fri 9 Oct"), with a link: "See it on the gift page". The state survives a reload.
- **C03.** C03 needed no change. `useProductReviews` already reads `data.reviews`, so the new review appears first on C03. It appears in the swipe row and in the all-reviews sheet, and it counts towards the average and the review count.
- **Orders with several products.** C15 shows one button per distinct product, labelled "Write a review: {name}". The seed has no such order, so this case was not driven in the browser.

**Files created**
- `front-end/src/features/reviews/lib/review.ts`: `reviewId`, `reviewerName`, `buildReview`
- `front-end/src/features/reviews/hooks/use-order-reviews.ts`: the order's reviewable products and `submit`
- `front-end/src/features/reviews/components/write-review-sheet.tsx`: the C18 sheet
- `front-end/src/features/reviews/components/order-reviews.tsx`: the C15 slot (button, or the posted review)
- `docs/ux/prototype/reports/1.16-drive.mjs`: the verification script

**Files changed:** `i18n/en.ts` and `i18n/de.ts` each got one `review.*` block (16 keys) at the end. See also §3.
