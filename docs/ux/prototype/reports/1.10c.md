# 1.10c: M03 ticket card uses the M02 card surface

## 1. What I built

**Root cause:** the 1.10b ticket copied the lab's outer surface, `rounded-2xl border border-separator … hover:border-foreground`. The M02 Today cards (`merchant-today.tsx:66`, `:97`) use `rounded-3xl bg-surface shadow-surface`, with no border and `hover:bg-surface-secondary`.

**Change:** one class string in `front-end/src/features/merchant/orders/components/order-rows.tsx`, on the ticket's outer `<a>`:

- Before: `flex flex-col overflow-hidden rounded-2xl border border-separator bg-surface outline-none transition-colors hover:border-foreground focus-visible:focus-ring`
- After: `flex flex-col overflow-hidden rounded-3xl bg-surface shadow-surface outline-none hover:bg-surface-secondary focus-visible:focus-ring`

I removed `transition-colors` because the M02 cards have no transition. `overflow-hidden` stays so the inner rules are clipped to the 24px radius. The skeleton in `merchant-orders.tsx` was already `rounded-3xl`, so it needed no change.

**Inner structure, kept unchanged:** the date tile's vertical divider (`border-separator`) and the dashed payment separator. Neither clashes: both read on white and on the hover grey (`m03-hover-en.png`).
