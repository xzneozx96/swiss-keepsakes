## Review the changes

The step follows [the outline, section 4](../flow-4-outline.md#4-mock-data-and-model-changes).

- **New types.** `features/content/types.ts` holds articles and comments. `features/requests/types.ts` holds the advice question set, advice requests, the C21 draft and private-tour requests.
- **Demo data.** `DemoData` gains `pickupPlaces`, `articles`, `comments`, `adviceQuestions`, `adviceRequests`, `adviceDraft` and `privateTourRequests`. `Review` gains an optional `reply`. `Product` gains an optional `published`, and `catalog/lib/publish.ts` treats a missing value as published.
- **Stored state (D5).** `features/demo/upgrade.ts` fills any missing collection from the seed when the app loads, and stored values win. It also holds the earlier tour and tour-review backfill, moved from `demo-store.tsx`. `DEMO_VERSION` stays 12.
- **Pickup places (D4).** The static `pickupPlaces` export is gone. All 15 readers now use `state.data.pickupPlaces`, and `renderMail` takes the places as a parameter. The seed constant `pickupPlaceSeed` is imported only by `demo/seed.ts`.

## Note demo assumptions and open items

- Article `tourIds` hold `Tour.id` values such as `old-town`. Reviews and favourites use `tour:old-town`. Later steps must convert explicitly.
- The EN Lion Monument article links the night tour, which runs in German only. The article text says so.
- The tour review reply is in German, so in an EN interface C09 needs the language notice (step 4.16).
- Mails render with the current pickup places, not a copy taken when sent. After an M14 edit, old mails show the new hours. Steps 4.11 and 4.17 decide whether this is acceptable.
- `npm run build` rewrote `front-end/dist/`, the source for `build:artifact`. No Artifact was published.
- `.claude/launch.json` at the project root now defines two local dev servers: `front-end` on port 5199 and `front-end-nohmr` on port 5232 for the regression drives.
- Another session edited `tour-booking-list.tsx` and `transaction-list.tsx` during this step, adding `break-words hyphens-auto` to row titles. Those edits are not part of 4.1 and were left unchanged.
