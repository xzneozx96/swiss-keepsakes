## 1. What I built

**Screen:** C14 My transactions, shown on the Account tab (`/account`) under the profile card when a guest is signed in. The signed-out sign-in prompt from step 1.6 is unchanged.

**Rows.** Rows are stacked, newest first (T0 `useGuestOrders`), and separated by dividers. Each row shows:
- product photo
- product name from the order's first-line snapshot (AC15), with "+N more" for more lines (two lines at most)
- order total
- `SK-1012 · Pickup 09.10.2026`
- progress label and payment label, both T0 `useOrderSummary(order, "guest")` → `StatusChip`
- the R04 free-cancel note, wrapped in `ProposalMark`. It shows only when the seller changed the date or place **and** T0's `cancelBlock(order, "guest")` allows a guest cancel (accepted, nothing paid, nothing processing). So the note disappears once the guest pays.

Each row is a link to C15 with a focus ring, press-scale and a chevron.

**C15 path (for step 1.13):** rows link to `#/account/orders/<orderId>`, for example `#/account/orders/sk-1015`. The order `id` is the lowercased ref. Because that route does not exist yet, the row uses a plain `href` (hash history), not a typed `Link`, which would fail `tsc`. **Step 1.13:**
- Create the route as `routes/_guest/account_.orders.$orderId.tsx`. The trailing underscore keeps it out of `account.tsx`, which has no `<Outlet/>`.
- Once that file exists, change `href` in `features/transactions/hooks/use-transaction-row.ts` (and the `<a>` in `transaction-list.tsx`) to a typed `Link`/`RouterLink`.

Until 1.13 lands, tapping a row shows the app's own not-found screen ("This page does not exist. It may have moved in the prototype." with "Back to Explore"): `row-tap-before-1.13.png`.

## 5. Open questions for the owner

1. **Demo-path conflict.** Outline §1 step 11 says "C14 shows both orders" (the knife and the gift box). With the seed, C14 then shows four rows. Should the seeded orders stay, or be removed once step 1.7 creates real orders?
2. **Long payment labels wrap inside the chip.** At 375px, "Payment due · CHF 64.00 by 14.10.2026, 07:00" and DE "Vollständig bezahlt · CHF 48.00" break onto two lines, and the chip's 14px icon then shrinks. The fix belongs in the shared `StatusChip` (`shrink-0` on the icon) or in shorter label copy. I did not change it, because `StatusChip` is not mine.
3. **The print's name stays English in DE.** "Limited-edition print: Water Tower at dawn" has no DE text in the catalogue, so the R02 single-language fallback applies. C14 does not show a translation notice, unlike C03. Is that OK for a list row?
4. **DE wording.** "Meine Transaktionen" follows the spec's screen name. "Meine Bestellungen" may read more naturally to guests, since flow 1 only has gift orders.
