## 1. What changed visually

### M05 Tour departures (`features/tours/merchant/departures-page.tsx`)

**Phones (below 1024px).** Each departure was a `DetailCard`: an icon header, a 2×2 fact grid, chips, and an "Open guest list" text link. It is now an M03 pickup ticket:

- **Surface.** The whole ticket is one link to M06. It has the M03/M02 surface (`rounded-3xl bg-surface shadow-surface`, no border, `hover:bg-surface-secondary`, focus ring) and a chevron.
- **Header.** The date tile (weekday, day, month beside a rule, via the shared `DateTile`), the tour name as the ticket title, and the full start date and time under it.
- **Body.** The phase (Open, Ended, Cancelled, Booking closed) and each attention item are shown as a coloured dot and words, as M03 shows progress. With nothing to do, it reads "Nothing to do" in muted grey.
- **Footer.** A dashed rule, then one fact per row: Booked (bold, like M03's Order total), Active holds, Free seats, To collect.
- **Cancelled departures.** The date tile is muted (the `DateTile` `muted` state for closed items).

**From 1024px.** M05 keeps its Table, as M03 does. Only the second lines changed: they now use M03's `text-label` size.

### M02 tour work (`features/tours/merchant/today-queue.tsx`, the `tours` slot of the Today part)

Before, the tour work was one `Widget` holding task rows with chevrons, the next departures and a text footer. It is now in the 1.9t widget look:

- **Section header.** "Tours" with its description and the "All departures" link, laid out like a widget header.
- **Task tiles.** Each open task is its own `StatCard` link: icon chip, round up-right `ArrowButton`, name, count and hint. Tiles are 2 across on phones and 4 across from 1024px, the same grid as the gift Today tiles.
  - The count keeps its tone: brick for overdue and reconcile, amber for results to record and delivered-but-owed. That is how the old rows coloured it.
  - The tile's accessible name is still "{task}, {count}".
- **Next departures.** These stay list rows with chevrons, as the 1.9t rule keeps for Next pickups. They now sit in their own `Widget`, laid out like the gift Next pickups widget.
- **Tour balances to collect.** This was a footer sentence. It is now its own `StatCard` (wallet icon, large value) beside Next departures. The row is the gift 3:2 Next pickups / Still to collect row. Tour money stays a separate figure from the gift "Still to collect" (AC19).

### Copy (`features/tours/merchant/messages.ts`, my file)

- `tourMerchant.todayCollect` is now the card label: "Tour balances to collect" / "Offene Tour-Restbeträge". The `{amount}` placeholder moved into the card value.
- `tourMerchant.openManifest` ("Open guest list") was removed. The whole ticket is now the link, so the key had no use left.

### Small shared helpers (my file `features/tours/merchant/shared.tsx`)

- `ToneLine`: M03's dot-and-words status.
- `toneText`: the tone colour map.

## 5. Left alone (would need a UX change), for the owner

1. **Zero-count tasks.** The gift Today shows all four tiles and mutes a tile at 0. The tour part shows only open tasks, as before. Showing the zero tiles would add content.
2. **Tour balance card is not a link.** The gift "Still to collect" widget links each stage to an M03 tab. Making the tour figure open M05 would add navigation.
3. **Date tile size.** R2's shared `DateTile` (`md`) uses a 24px day number. The M03 ticket's inline tile uses 30px. M05 follows the shared component. Should M03 move to `DateTile` too, so all tickets match?
4. **"Open guest list" text.** It is gone because the whole ticket is the link (the M03 pattern). If the owner wants a visible text link, the ticket cannot also be a link.
