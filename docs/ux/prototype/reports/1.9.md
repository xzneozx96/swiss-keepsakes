# Step 1.9 report: M02 Merchant Today

## 1. What I built

M02 Today at `#/store` (replaces the placeholder). Owner and Manager see the same page; there is no role gate.

- **Header:** "Today" and the demo date as a short date ("Tue 13 Oct" / "Di., 13. Okt.").
- **To do:** task cards in priority order:
  1. awaiting confirmation
  2. awaiting payment
  3. to prepare
  4. ready for pickup
  5. payment overdue
  6. handed over, balance owed

  Each card shows an icon, a title, a one-line hint and the count. The whole card is a typed `Link` to `/store/orders?status=<tab>`, and its accessible name includes the count in words ("Awaiting confirmation, 3 orders"). The overdue card uses a danger tint, a danger icon and danger words. Cards with a count of 0 are hidden.
- **At a glance:** three numbers in one card: still to collect, commission to pay, completed this week (with the week range).
- **States:**
  - Skeleton on load (`useSimulatedLoading`).
  - Empty: "No tasks. New requests will show up here." with one action, "See all orders" (→ `/store/orders`). The numbers stay visible.
- **Layout:** at 375px the tasks come first and the numbers follow (spec §1.6: the to-do list comes first). From 1024px there are two columns: tasks on the left and a 320px numbers column on the right, as on M04.
- **Logic:** every count and amount comes from T0 selectors over `state.data.orders`: `balance`, `commission`, `isOverdue`, plus 1.10's `orderTab` for the overdue link. The only local logic is the Monday–Sunday Zurich week.

### `status` search param (agreed with 1.10)

The values are 1.10's `ORDER_TABS` (`features/merchant/orders/lib/order-tabs.ts`). M02 imports the `OrderTabId` type, so a wrong value fails `tsc`.

| Card | `?status=` |
| --- | --- |
| Awaiting confirmation | `awaiting-confirmation` |
| Awaiting payment | `awaiting-payment` |
| To prepare | `preparing` |
| Ready for pickup | `ready` |
| Payment overdue | the tab of the overdue order with the soonest pickup: `awaiting-payment` for a missed first payment, otherwise `preparing` / `ready` / `owing` for a missed balance due date |
| Handed over, balance owed | `owing` |
