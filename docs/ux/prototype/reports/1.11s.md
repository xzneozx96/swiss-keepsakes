  - **FulfilmentActions "Still owed" panel.** A single inset fact.
  - **M08 "Still owed / Total / Paid" summary** (`record-payment-sheet.tsx`). One inset panel, no dividers.
  - **Commission lines.**
  - **`divide-y` lists** (gifts, order log). These are list rows.
- **The pattern.** I copied the P02 KPI row (`partner-report.tsx` `KpiBlock`, approved in round 2):
  - `dl.grid grid-cols-2 gap-3 lg:grid-cols-4 lg:gap-4`, with one shared `StatCard isSubgrid` per fact.
  - Each card has the icon chip, the label, the value and the hint in a `dd`.
  - The surface is `rounded-3xl bg-surface shadow-surface` with no border, via StatCard.
  - Subgrid keeps the values aligned along a row when a label wraps (DE "Gewünschte Abholung").
- **evon:ui-ux pass.**
  - **Route:** "smaller than one screen", with no wireframe.
  - **Audit:** Vite + React 19, Tailwind 4, HeroUI v3. The shared `StatCard` already exists, so I reused it. The style is the project's flat surface with a soft shadow.
  - **Checked against `components/charts.md` "Ô số liệu ở màn hẹp"** (stat tiles on narrow screens). Every point passes:
    - 2×2 on phones, 4 across from 1024px
    - `min-w-0` on each card (from StatCard)
    - values aligned by a row subgrid
    - `tabular-nums`
    - the value at `text-xl`
  - **Width check.** At 375px the value has about 133px of inner width. "CHF 1'234.50" is about 125px, so it fits.
  - **Skill default overridden.** The skill's default for a stat row is one block divided by `divide-x` (`charts.md`, "Hàng ô số liệu", the stat-row rule). The owner explicitly rejected that pattern here and for 1.9t, so the owner's verdict wins.
