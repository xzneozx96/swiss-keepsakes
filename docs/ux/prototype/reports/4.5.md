# C21 Trip assistant

14 October 2026. Step 4.5 is rebuilt as a chat; approved by the owner 14.10.2026. Built directly in the React app.

The first build was a step-by-step form. The owner then set the direction (14.10.2026): C21 is a chat with the shop's AI assistant, and for now a scripted one. This is recorded as R19 in the PRD (§12, scope table, AC34, open item O19 for the real AI agent), the UX spec (§1.3, §4.10, R19, C21, AC34) and the Phase 4 checklist and outline (D14). The old rule "never say AI" now applies everywhere except this assistant.

## Review the changes

Tap the floating "Trip advice" button (C01, C09, C20) or "Ask a local" on C01; both open `#/plan`. Try it in EN and DE.

- **A chat with the AI assistant (R19).** The header shows the assistant's avatar, "Trip assistant" / "Reiseassistent" with an "AI" / "KI" label, and the shop. The assistant greets the guest ("Grüezi! I'm the AI travel assistant of Swiss Keepsakes Luzern.") and says the team reads the answers and replies by email.
- **One question per message**, in the shop's order. The composer at the bottom shows the matching input: the large − n + counter for numbers (adults start at 1, children at 0), quick-reply buttons for choices (a single choice answers on tap; multiple choices toggle with a check, then Send), the calendar for dates, a text box for text. Each answer appears as the guest's message on the right; a skipped optional question shows "Skipped".
- **Scripted for now.** The assistant asks only the configured questions. There is no free message box, so nothing typed freely gets an answer, and it generates no plan.
- **Required and optional.** Sending an unanswered required question shows "Please answer this question to continue."; optional questions are marked "Optional" and offer "Skip".
- **Back.** The arrow in the header returns to the previous question with its answer.
- **Missing translation (D7).** The seeded "Anything else?" question has no German text; in DE the message shows it in English with "Diese Frage gibt es nur auf Englisch."
- **Email (AC18, R08).** The assistant asks which email the team should reply to; the composer explains the use ("We use it only to reply to this request."). Empty or malformed addresses are caught. No sign-in.
- **Summary, then Send.** The assistant posts a card with every answer and the email, each with "Change"; changing an answer returns to the summary. "Send to the team" sends.
- **Thank-you.** "Thank you! Our team has received your details and will contact you at … to continue the conversation.", then the answers as sent and "Back to Explore". No reply time.
- **Saved request and draft.** Unchanged from the first build: each answered question is saved with its wording and language as shown, plus the guest's language and email; the conversation survives a refresh; an edit by the shop applies to new conversations only. M19 (step 4.14) lists requests; the N16 email comes in step 4.17.

## Owner review, 14.10.2026 (second round)

- **Choices in the conversation.** Single and multiple choices now appear under the assistant's question, in the C03 gift option style: a chosen option gets the red border and the red check on its top edge. A single choice answers on tap; multiple choices go with Send.
- **Smoother chat.** Following the Chatwoot widget ([research](../../research/chatwoot-widget.md)): the screen fills the phone height with the header and composer fixed and only the conversation scrolling; after each answer the assistant shows a typing bubble for 0.65 s, then its message rises in; Back, Change and reload skip the pause, and reduced motion turns both off. Dates open in a bottom sheet, so the composer stays compact.
- Rerun: [4.5-capture.mjs](4.5-capture.mjs) 76 passed, 0 failed, including the in-conversation choices and their selected style, the date sheet, the page not scrolling, and the typing bubble before the next question (checked with normal motion). New screenshot `c21-typing`.
