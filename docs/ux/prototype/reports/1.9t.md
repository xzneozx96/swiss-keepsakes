# Step 1.9t report: standalone stat cards, arrow link affordance, all-time widgets, one red chart theme

The owner gave three pieces of feedback on the dashboards after 1.9s and 1.17r:

- **Joined KPI groups.** The owner wanted each figure split into its own card. This covers the M02 Today tiles, the M02 KPI group and the P02 KPI row.
- **Chevron link icon.** The chevron on linked cards becomes a round button with an arrow pointing up and right.
- **All-time summary.** The owner asked for an "all-time" summary widget like the "Earning insights" reference.

Mid-task, the coordinator relayed a fourth piece of feedback: "one single solid theme … red-ish". The blue, aqua and violet chart palette is replaced with one red-based chart token set, shared by both dashboards.

## 0. Brief and plan (evon:ui-ux "build directly", dataviz)

  - Before this step, both dashboards drew their KPI cards inline (`Kpi`/`KpiGroup` in `overview-analytics.tsx`, `KpiBlock` in `partner-report.tsx`). There was no shared card.
  - I built one shared card, `src/components/stat-card.tsx`, rather than two local copies.
  - The style is flat with the soft surface shadow (`rounded-3xl bg-surface shadow-surface`, no border), as agreed.
- **dataviz.**
  - Form: a hero figure plus a 7-bar chart with the running bar highlighted, and meters.
  - Each meter's reference is written as text ("75% of CHF 12'016.00 requested").
  - Bars have a hover tooltip and a screen-reader table.

  - **M02.** The all-time card sits under the "Analytics" heading and above the period row, so it does not read as filtered by "7 days".

## 1. What I built

### Shared component: `front-end/src/components/stat-card.tsx` (new)

- **`StatCard`:** one card per figure.
  - Contents: an optional icon chip, the label, the value, an optional badge (the delta chip) and an optional child (a sparkline or a hint). As a plain card it uses `dt`/`dd` inside a `dl`.
  - With `as`, the card renders as a router link and its text becomes `aria-hidden`. The link carries the accessible name, as the 1.9r tiles did.
  - `isLink` shows the arrow button.
  - The label grows, so values line up along a row.
  - `isSubgrid` uses a row subgrid, so values line up even when hints wrap to different heights. P02 uses it, as 1.17r did.
- **`ArrowButton`:** a 32px circle (`bg-surface-secondary`) holding `ArrowUpRightIcon` (16px). On hover over the card it inverts to ink.
- **`DeltaChip`:** moved here from `overview-analytics.tsx` so P02 can use it. It looks the same as before.
- **`AllTimeCard`:** the "Earning insights" pattern.
  - Title and subtitle.
  - A hero figure (36px on phones, 48px from 768px), the delta chip and one sentence.
  - A Recharts `BarChart`: past bars `--chart-1-light`, the running bar `--chart-1`, 8px radius, a hover tooltip, and an sr-only table.
  - An inset `bg-surface-secondary` panel with three sub-figures. Each has an icon, label, value, a thin `--chart-1` meter on a `--chart-track` track, and a caption naming the meter's reference.

### Chart theme (coordinator follow-up "one single solid theme, red-ish")

- **Tokens.** New block in `front-end/src/styles/theme.css`:
  - `--chart-1` Swiss red #d52b1e
  - `--chart-2` ink (`var(--foreground)`)
  - `--chart-3` warm grey #9a9893
  - the ordinal ramp `--chart-1-dark` #b32418, `--chart-1` #d52b1e, `--chart-1-mid` #e26b62, `--chart-1-light` #ec9790
  - `--chart-track` #fce9e7 (the value of accent-soft)

  `theme.css` is light-only: it pins the light values even when a host sets `data-theme="dark"`. So these tokens serve both the light case and the dark-host case. There is no separate dark set.
- **Removed:** the local palette in `overview-analytics.tsx` (#2a78d6 blue, #1baf7a aqua, #6250d6 violet).
- **Where the tokens are used:**

  - **Payment methods** (fixed per method): online red, cash ink, bank transfer grey, other muted.
  - **Product groups and pickup places.** Red bars on the red track.
  - **Funnel.** The red ordinal ramp; declined and cancelled are grey.
  - **Today's "Still to collect" bar.** The red ramp, light to dark along the stages.
  - **P02 chart and groups.** As described above.
  - **Both all-time widgets.**
- **Status colours stay separate:** delta chips are green (good) or brick-soft (bad, `--danger` #9a3412), overdue is brick, success is green.
