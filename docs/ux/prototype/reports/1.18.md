How the scripts work:
- **Labels.** Labels are read from the live `en.ts` and `de.ts`, so the same script asserts the real copy in each language.
- **Clock.** The demo clock is pinned through `clockStartedAt` to 10:30 for the gift-box accept and 10:35 for the knife, so the deadline strings can be compared exactly.
- **Per-screenshot checks.** Every screenshot also checks two things:
  - horizontal overflow is 0;
  - no raw i18n key and no literal `{param}` is visible;
  - **DE only:** no hardcoded English. The scan looks for 453 English fragments: every EN value of 12+ characters (outside `{params}`) whose DE value differs and that appears nowhere in `de.ts`. The Prototype bar is excluded. Mail panel screenshots don't run this check, because each email renders in its own language. It ran on every DE screenshot, with no hits. This is why DE has more checks than EN.
- **Errors.** Every run checks that the console and page show no errors.

To run a script, copy `1.18-*.mjs` into a folder whose `node_modules` points to `~/.npm/_npx/e41f203b7505f1fb/node_modules`, then run `node 1.18-main.mjs en`. The screenshot path is fixed to `docs/ux/prototype/screens/1.18/`.
