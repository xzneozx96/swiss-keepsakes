## Verification

- `5.1-selfcheck.ts`: all pass. Per partner: earned − paid = still to pay − still to offset; never negative and never both owed and overpaid; per-transaction settled amounts sum to earned − still to pay and never exceed a transaction's net commission; the 30-day open count excludes older opens. Each 5 October payout equals that partner's P02 September commission. Live cases: completing SK-1028 (6.40) is fully offset; completing the SK-T1049 booking (35.70) offsets 11.10, leaves 24.60 owed, and the booking is partly paid. Also: Hotel am See has an offset and a carry-over, Guide Sophie's link is revoked, five transactions miss one cost, delivery is not applicable everywhere, and `upgradeDemoData` fills the new collections for data stored before Phase 5.
- `5.1-history.ts`: the history's partner commission per month, the evidence behind D14.
- Typecheck: no errors in any file changed here. The full typecheck currently fails only in Phase 4's in-progress `features/content/components/stories-page.tsx` (its `stories.*` translation keys are not added yet). ESLint clean on every changed file. The production build passed before the Phase 4 change and is rechecked in 5.14.
- Browser, at 430px: a browser holding pre-Phase 5 demo data loaded with the three partners, 5 payouts, 1 adjustment and 135 cost records filled in. `#/r/SOPHIE` recorded a Guide Sophie visit through the new lookup. P02, M04 (SK-1017, "Source: Hotel am See") and M07 (SK-T1049, Hotel am See) render with no console errors.

## Fixed during review

The advisor review found that the per-transaction settled amount counted offsets as new money, and that the first self-check repeated the same formula, so it passed. An offset only moves overpaid money, so money paid alone now covers recorded commission, oldest first. The check now compares against earned − still to pay, and the two live cases above cover it. History and seed timestamps use different formats (`Z` and `+02:00`), so sorting now uses `Date.parse` and month matching uses Zurich dates.
