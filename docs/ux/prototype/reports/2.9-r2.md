## 1. What changed visually

**C14 tour bookings (`tour-booking-list.tsx`).** Each booking is now the gift C14 pickup ticket (1.12r):
- date tile, then the tour name in serif with the start time (clock icon) and the group, then a 56px thumbnail;
- a dashed rule, then both status chips, then the reference and a chevron;
- the shared surface: `rounded-3xl`, `shadow-surface`, no border, `active:scale` and the focus ring.

The date tile is muted on closed bookings (expired, cancelled, completed, no-show), as on C15. Before, each row had a full-width photo on a `rounded-2xl` grey hover card. The list is still one list, newest booking first. Same content: name, date and time, group, both chips, reference.

I keep it as a quiet `text-sm` line in the money card, not a headline, so it does not compete with the hold timer (`drive/c16-held-en.png`). 6. **Rules inside cards.** C16 cards use `SurfaceCard`'s fine solid dividers, so they match R1's C13. Gift C15 uses dashed rules between items and amounts. The activity card keeps the shared stepper's `p-4` against `p-5` in the other cards, because the stepper is the gift's component.
