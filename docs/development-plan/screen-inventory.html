  • Guest tab bar: Explore, Keepsakes, Tours, Account, with the language prefix. E4.6 swaps Tours for Map (gate G-S5-MAPTAB, 27.10.2026). Stories are reached from Explore.

Skip on step 1 goes to step 2. Full spec: docs/ux/onboarding-design.md.
  • Map and pins design (28.10.2026): approved as the lab page /lab/pins opens: guest map and pin card as option B "Cards", merchant pins list, and merchant editor as option S "Steps". The PRD was changed to match (Google Maps link, several photos, Categories sheet, Map and List switch). The folded map credits stay open. N23 and N18 are not designed. Spec: docs/ux/pins-design.md.
  • Map chips: chips come from merchant-edited map categories. Selecting one highlights those pins and dims the rest. No pin is ever hidden. A pin with no category shows under All only.

  • Map style (O23 closed, 27.10.2026): no reference images. The default style of MapLibre with swisstopo SWISSIMAGE and OpenFreeMap names, flat 2D.
